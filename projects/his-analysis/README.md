# تحلیل گزارش اقلام بخش‌ها از HIS

`analyze_his.py` گزارش اقلام بخش‌ها از HIS (طراح داده / پیشرو) را با فایل «عملکرد بخش‌ها» (تخت‌روز ماهانه) ترکیب می‌کند. خروجی آن این‌هاست:

- دستکش: تعداد و ارزش به تفکیک نوع و بخش، دستکش معاینه به ازای تخت‌روز، تغییر قیمت خرید، سهم ثبت‌شده روی پرونده
- آلبومین: ویال، ارزش، ویال در ۱۰۰ تخت‌روز، سهم بیمه و بیمار، قیمت هر کد
- محدودیت‌های داده

```bash
python analyze_his.py --his "<گزارش اقلام>.xlsx" --wards "<عملکرد بخش‌ها>.xlsx" --label "1405 فروردین تا شهریور"
```

> داده واقعی و خروجی‌ها در git ذخیره نمی‌شوند (`output/` و `*.xlsx` در `.gitignore` هستند).

## نکات ساختار گزارش HIS

- هر ردیف = قلم × بخش × قیمت خرید. مقدار «تعداد» خروج ثبت‌شده برای بخش است، نه مصرف شمارش‌شده.
- ستون «حواله از انبار» در خروجی فعلی همه صفر است.
- «مانده» موجودی کل داروخانه است و در همه ردیف‌های یک قلم تکرار می‌شود. جمع زدن آن اشتباه است.
- ردیف آخر فایل جمع کل است و حذف می‌شود.
- ردیفی که سهم بیمه و سهم بیمار آن صفر است، هزینه بخش است (روی پرونده بیمار نرفته).
- نام بخش‌ها در دو فایل متفاوت است. نگاشت در `WARD_MAP` تعریف شده است.

## تحلیل ماهانه استوک بخش‌ها

`monthly_stock.py` گزارش‌های ماهانه اقلام بخش‌ها (استوک، بدون سهم بیمه و بیمار) را کنار هم می‌گذارد: دستکش هر بخش در هر ماه، دستکش به ازای تخت‌روز، قیمت خرید ماهانه، ارزش استوک هر بخش و ۴۰ قلم پرهزینه.

```
python monthly_stock.py --wards ward_indicators.xlsx \
  --file فروردين=far.xlsx --file ارديبهشت=ord.xlsx --file خرداد=kho.xlsx \
  --file تير=tir.xlsx --file مرداد=mor.xlsx --file شهريور=shah.xlsx
```
نام ماه باید همان نام ستون فایل عملکرد بخش‌ها باشد (با «ي» عربی هم کار می‌کند).

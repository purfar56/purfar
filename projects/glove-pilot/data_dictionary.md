# مشخصات داده موردنیاز (برای درخواست از فناوری اطلاعات)

همه فایل‌ها CSV با کدگذاری UTF-8 هستند. تاریخ‌ها شمسی با قالب `YYYY/MM/DD`. هر فایل باید کل دوره را پوشش بدهد. اسکریپت فقط ردیف‌های همان دوره را می‌خواند.

برای اجرای آزمایشی، اول یک ماه گذشته استخراج شود تا نام جدول‌ها و فیلدهای HIS معلوم شود.

## داده عملیاتی (از HIS و انبار)

### receipts.csv — ورود به انبار مرکزی
| ستون | توضیح |
|---|---|
| date | تاریخ رسید |
| doc_no | شماره رسید/فاکتور |
| supplier | تامین‌کننده |
| item_code | کد کالا (مطابق `config/items.csv`) |
| qty | مقدار |
| unit | واحد (عدد، جفت، بسته، کارتن) |
| unit_price_per_base_rial | قیمت خرید هر **عدد** دستکش (ریال) |

### issues.csv — حواله انبار به بخش
`date, doc_no, item_code, ward, qty, unit`

### returns.csv — برگشت از بخش به انبار
`date, doc_no, item_code, ward, qty, unit`

### stocktake.csv — شمارش فیزیکی
| ستون | توضیح |
|---|---|
| date | تاریخ شمارش |
| location | کد بخش یا `CENTRAL` برای انبار مرکزی |
| item_code | کد کالا |
| qty_base | تعداد شمرده‌شده به **عدد** |
| count_point | `opening` (اول دوره) یا `closing` (پایان دوره) |
| counted_by | نام شمارنده (و ترجیحاً شاهد دوم) |

> شمارش شامل موجودی اتاق کار، ترالی‌ها و کمدهای بیمار هم هست. بسته‌های باز را تخمینی نشمارید. اگر شمارش دقیق ممکن نیست، روش را در یادداشت ثبت کنید.

### charges.csv — ثبت مصرف روی پرونده بیمار
| ستون | توضیح |
|---|---|
| date | تاریخ ثبت |
| line_id | شناسه یکتای سطر صورتحساب |
| admission_id | شماره پذیرش (برای گزارش‌های عمومی ناشناس شود) |
| ward | بخش ثبت‌کننده |
| item_code, qty, unit | قلم و مقدار |
| tariff_price_per_base_rial | قیمت هر عدد در صورتحساب |
| insurer | بیمه پایه |

### claims.csv — نتیجه رسیدگی بیمه
`line_id, admission_id, insurer, billed_rial, deducted_rial, deduction_reason`

> اگر کسورات در سطح سطر صورتحساب در دسترس نیست، سطح پرونده هم قابل استفاده است. در این حالت سهم دستکش از کسورات پرونده با واحد درآمد مشخص شود.

### activity.csv — حجم فعالیت
`period, ward, activity` (تخت‌روز اشغالی برای بخش‌های بستری؛ تعداد ویزیت برای اورژانس)

## جدول‌های تنظیمات (config/)

| فایل | محتوا | تأییدکننده |
|---|---|---|
| items.csv | کد، نام، گروه (nitrile/vinyl)، سایز، کد HIS | انبار، فناوری اطلاعات |
| units.csv | ضریب تبدیل هر واحد به عدد (`*` = همه اقلام) | انبار |
| billing_rules.csv | قابل اخذ بودن (`yes`/`no`) و تعرفه هر عدد | درآمد، اسناد پزشکی |
| norms.csv | معیار مصرف به ازای فعالیت برای هر بخش و گروه | ناظر دارویی، کنترل عفونت، پرستاری |
| wards.csv | کد و نام بخش و نوع فعالیت | پرستاری |

## کنترل‌های کیفیت داده که اسکریپت انجام می‌دهد

- واحدی که ضریب تبدیل ندارد
- کد کالای ناشناخته
- نبود شمارش اول یا پایان دوره برای بخشی که تحویل یا ثبت دارد
- مصرف منفی (معمولاً خطای شمارش یا حواله)
- ثبت روی پرونده بدون مصرف
- نبود تخت‌روز/ویزیت
- سطر بیمه بدون سطر صورتحساب متناظر

هر مشکل «بحرانی» در بالای گزارش مدیریتی هشدار داده می‌شود.

# دستیار ناظر دارویی

یک ایجنت (subagent) برای Claude Code که در کارهای نظارت و بازرسی دارویی کمک می‌کند.

## ساختار
```
.claude/agents/pharma-supervisor.md   # تعریف ایجنت
templates/inspection-checklist.md     # چک‌لیست بازرسی
templates/inspection-report.md        # قالب گزارش بازرسی
reports/                              # محل ذخیره گزارش‌ها و نامه‌های ساخته‌شده
projects/glove-pilot/                 # پایلوت ردیابی دستکش: ورود، تحویل، مصرف، هزینه و بیمه
```

## استفاده
در Claude Code داخل همین مخزن کافی است درخواستتان را بنویسید؛ Claude در موارد مرتبط ایجنت را خودش صدا می‌زند. برای فراخوانی صریح:

```
@pharma-supervisor یادداشت‌های بازدید امروز از داروخانه X را به گزارش رسمی تبدیل کن
```

نمونه درخواست‌ها:
- «این فایل اکسل موجودی را بررسی کن و اقلام زیر ۶ ماه تا انقضا را جدا کن.»
- «لاگ دمای یخچال این هفته را بررسی کن و انحراف‌ها را گزارش بده.»
- «یک اخطار کتبی برای عدم حضور مسئول فنی بنویس.»
- «چک‌لیست بازرسی شرکت پخش برایم آماده کن.»
- «این نسخه را از نظر دوز و تداخل بررسی کن.»

## نکته
ایجنت شماره بخشنامه یا ماده قانونی را از خودش نمی‌سازد؛ موارد قانونی را همیشه با آخرین دستورالعمل‌های سازمان غذا و دارو تطبیق دهید. تصمیم نهایی با ناظر است.
